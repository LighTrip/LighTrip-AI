# Reports Directory

## Main Report

The current model comparison report is kept at the top level:

```text
outputs/reports/ndcg_model_eval_comparison.md
```

## Folder Layout

| folder | contents |
| --- | --- |
| `model_evaluation/ndcg3_runs/` | per-model `NDCG@3` training reports and plots |
| `model_evaluation/latency/` | latency benchmark CSV, reports, and plots |
| `model_evaluation/legacy_comparison/` | older model comparison outputs |
| `training_runs/` | full training, overfit, and model-fit run artifacts |
| `sweeps/` | hyperparameter sweep and smoke experiment artifacts |
| `soft_label/` | soft-label v2 analysis, plots, and previews |
| `previews/` | generated visual recommendation examples |
| `architecture_experiments/` | architecture notes and experimental model summaries |
